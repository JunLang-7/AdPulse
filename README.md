# AdPulse

> 主动发现市场信号，辅助下一步投放决策。

AdPulse 是一款**主动式营销投放决策助手**，当前已交付可运行的 MVP，并在试点实例运行。

它围绕企业的推广目标与当前方案，持续关注外部市场信息和自身投放表现，主动发现值得关注的变化，帮助市场与营销人员判断下一步该延续什么、调整什么、尝试什么，以及什么时候应该暂停——市场动态是输入，**有依据、可控制、可验证的投放决策**才是目标。

## 为谁解决什么问题

面向需要持续对推广投入作出判断的市场与营销团队（试点期初步面向国内企业，不预设行业）。

市场信息与自身投放结果分散，变化难以及时发现，也难以转化为有依据的下一步决策。AdPulse 帮用户回答四个问题：

- 最近发生了哪些与当前推广有关的重要变化？
- 这些变化值得影响当前方案吗？依据是什么？
- 下一步应该调整卖点、内容、人群、渠道、合作对象，还是预算？
- 应该先做什么小规模验证、观察什么结果，再决定继续还是停止？

## 它怎么工作

**建立推广基线 → 持续发现信号 → 人工核实关键依据 → 判断对当前方案的影响 → 形成调整草案 → 用户确认行动 → 录入实际结果 → 更新下一轮关注。**

产品持续围绕三类信号主动提醒：

1. **市场变化**：用户需求、竞品动作、内容方向及平台环境中与当前推广有关的变化。
2. **效果变化**：自身投放成本、有效咨询、成交等表现的变化。
3. **假设偏差**：当前方案依赖的判断开始得到支持，或受到新证据挑战。

外部信息来自本人登记的企业官网、公开搜索与小红书笔记线索；发现的结果一律先作为**待核验线索**进入待审核列表，人工接受后才入库。新信息不一定代表变化，变化也不一定需要行动：没有历史对照时不把新发现包装成趋势，证据不足时明确建议继续观察。

每条调整建议都交代：发生了什么、原始依据在哪、哪些是事实哪些是推断、建议改变什么和需要多少投入、如何验证、什么情况下继续 / 调整或停止。

## 方案是判断基线，不是使用门槛

- **已有方案**：理解你的目标、受众、渠道、预算与执行安排，作为持续观察和提出建议的基线。
- **没有方案**：AI 根据你提供的真实业务材料生成起步草案，由你确认；缺失信息如实标为未知，不编造预算、历史效果或经营目标。

方案不是一次生成后就结束的文档，而是持续回答「现在为什么这样投」的依据。重要性判断给出可解释的理由与原文摘录，不依赖一个黑箱综合分数。

## 用户可控

- **关注范围**：关注哪些对象、来源与渠道，排除什么。
- **提醒条件**：哪些事件立即提醒、哪些进入定期汇总；可量化的变化可设置明确阈值。
- **行动边界**：可用预算、可接受的试验范围，以及必须人工确认的事项。

默认方式让你直接开始使用，自定义用于逐步纠偏，而不是先完成复杂配置。提醒可开关、可退订；企业飞书登录后，决策卡片、每日汇总与实时提醒直达单聊，控制台提供任务、方案假设、市场与竞品事件、线索审核与通知记录的完整操作界面。

## 投放范围与效果衡量

同时考虑三类投放方式，并按各自口径衡量：平台付费广告（花费 / 咨询 → 单次咨询成本）、达人合作（费用 / 互动 → 单次互动成本）、内容种草（内容成本 / 互动 → 单次互动成本）。

不同口径的指标不混用、不直接比较；互动量不等于咨询或成交，曝光与热度不能换算成利润，归因局限随比较结果一起展示。外部市场信息帮助发现值得验证的方向，自身真实投放数据帮助判断是否继续投入。

## 我们承诺不做的

- **不自动操作广告平台**：一切策略变更经用户确认，不自动改预算、下单投放或中止合作。
- **不编造**：缺失数据如实标注未知；模型引用逐字可溯，推断不冒充事实。
- **不打扰**：未确认的结论不推送；提醒频率与渠道由用户掌控。
- **数据有期限、可删除**：任务数据到期自动限访，支持本人确认删除、在线清理与审计留痕。

> AdPulse 处于探索期：以上为 MVP 已交付范围，部分场景仍在建设中，产品范围、用户细分与商业模式待真实使用验证——不把工程演示当作已验证的结论。
